# **App Name**: Teenger

## Core Features:

- Random Chat: Start a random one-on-one chat with another user.
- Text Messaging: Allow users to send text messages in the chat.
- AI Chatbot: Allow users to chat with Gemini AI. The AI can serve as a 'tool' when needed, participating as another member of the chat.
- Chat next: A prominent button will appear when the user disconnects from the previous chat, that will immediately take them to another chat.
- Moderation: Implement basic moderation tools to ensure appropriate behavior.

## Style Guidelines:

- Primary color: Vibrant blue (#29ABE2) for a modern and inviting feel. Teenagers love to be social.
- Background color: Light gray (#F0F0F0), providing a clean and neutral backdrop.
- Accent color: Electric purple (#8E24AA), used to highlight interactive elements.
- Font: 'Poppins' (sans-serif) for a contemporary, precise feel.
- Clean and spacious layout with a focus on readability and easy navigation.
- Use of minimalist, custom icons for key functions. Use thin strokes to reflect the line height used in the 'Poppins' font.
- Subtle transition animations to indicate loading and newly available connections
